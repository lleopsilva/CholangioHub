# Objetivos do Projeto

---

# Objetivo Geral

Construir uma plataforma aberta para coleta, processamento, análise e disponibilização de informações sobre colangiocarcinoma.

---

# Objetivos Técnicos

## Engenharia de Dados

- Criar pipelines automatizados.
- Implementar Data Lake.
- Processar grandes volumes de documentos.
- Criar modelo analítico.

---

## Plataforma

- Disponibilizar API pública.
- Criar dashboard interativo.
- Implementar busca inteligente.

---

## Inteligência Artificial

- Extrair entidades médicas.
- Resumir literatura.
- Criar busca semântica.

---

# Objetivos Sociais

- Facilitar acesso à informação.
- Apoiar pacientes e familiares.
- Aproximar conhecimento científico da sociedade.

---

# Critérios de sucesso

O projeto será considerado bem sucedido quando:

- possuir atualização automática de dados;
- disponibilizar informações rastreáveis;
- permitir navegação simples pelo conhecimento;
- possuir arquitetura escalável.
