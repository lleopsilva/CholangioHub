# Segurança

---

# Objetivo

Garantir proteção da plataforma.

---

# Princípios

## Secrets

Nunca versionar:

- senhas;
- tokens;
- chaves.

---

## Autenticação

API utilizará:

- JWT;
- OAuth2 (futuro).

---

## Autorização

Perfis:

- administrador;
- pesquisador;
- usuário público.

---

## Dados médicos

A plataforma não armazenará:

- prontuários;
- dados pessoais de pacientes;
- informações identificáveis.

---

# Compliance

Considerar:

- LGPD;
- boas práticas de segurança.
