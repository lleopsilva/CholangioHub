# Padrão de Commits

---

# Conventional Commits

Todos os commits devem seguir:


tipo(escopo): descrição


---

# Tipos

## feat

Nova funcionalidade.

Exemplo:


feat(api): create article endpoint


---

## fix

Correção.


fix(parser): handle empty abstract


---

## docs

Documentação.


docs: update architecture


---

## refactor

Melhoria interna.


refactor(spark): optimize transformation


---

## test

Testes.


test(api): add endpoint tests


---

## chore

Manutenção.


chore: update dependencies
