# ADR-000 — Visão do Projeto

## Status

Accepted

---

# Contexto

O colangiocarcinoma possui informações distribuídas em múltiplas fontes científicas, clínicas e institucionais.

Existe dificuldade em encontrar informações:

- confiáveis;
- atualizadas;
- organizadas;
- acessíveis.

---

# Decisão

Criar uma plataforma open source chamada:

# CholangioHub

Uma plataforma de dados e conhecimento sobre colangiocarcinoma.

---

# Objetivos

- Centralizar informações científicas.
- Estruturar conhecimento médico.
- Disponibilizar dados publicamente.
- Criar uma base para análise e IA.

---

# Consequências

Positivas:

- maior acesso ao conhecimento;
- arquitetura escalável;
- possibilidade de colaboração.

Negativas:

- necessidade de governança;
- necessidade de validação científica.
