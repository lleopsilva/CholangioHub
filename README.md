# CholangioHub

Open Data & Knowledge Platform for Cholangiocarcinoma.

## Objetivos

- Centralizar dados científicos sobre colangiocarcinoma.
- Construir pipelines modernos de engenharia de dados.
- Disponibilizar APIs públicas.
- Apoiar pacientes, familiares, pesquisadores e profissionais de saúde.

## Stack

- Python
- Docker
- PostgreSQL
- MinIO
- ClickHouse
- Apache Spark
- Apache Airflow
- FastAPI
- Streamlit
